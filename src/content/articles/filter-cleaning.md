フィルター掃除は、初心者ができるエアコンメンテナンスの中で、もっとも費用対効果が高い作業です。フィルターが目詰まりすると空気の通り道が狭くなり、風量低下・冷えにくさ・におい・電気代のムダが同時に起こります。逆に言えば、掃除ひとつで4つの不調にまとめて効きます。

![フィルター、リモコン、温湿度計、室外機、ドレンホース先端など安全に確認できる範囲](/images/articles/basics-safe-check-zones.webp)

初心者が触ってよいのは、フィルター、リモコン、室外機まわり、ドレンホース先端のような「外側」です。内部の金属フィンやファン、電装部品へ手や道具を入れないことが、すべての確認の前提になります。

## 手順

1. **運転を止める。** 電源プラグを抜ける機種は抜く。
2. **前面パネルを開ける。** 多くの機種は両端に指をかけて手前に持ち上げる。固い時は無理にこじ開けず、型番で取扱説明書を確認。
3. **フィルターを外す前に、掃除機で表面のホコリを軽く吸う。** 外す時のホコリの落下を減らせます。
4. **フィルターを外し、掃除機で「外側（ホコリが付いている面）」から吸う。** 内側から吸うと目にホコリが食い込みます。
5. **汚れが強い場合は水洗い。** シャワーは「内側（きれいな面）」から当てると、ホコリが目から押し出されます。油汚れには中性洗剤と柔らかいブラシ。
6. **日陰で完全に乾かしてから戻す。** タオルで水気を取り、30分〜1時間が目安。
7. **元の向きに戻し、パネルを閉める。**

所要時間は掃除機だけなら5分、水洗いしても乾燥待ちを除けば15分程度です。

## 失敗しやすいポイント

| やりがちな失敗 | 起きること | 正しいやり方 |
| --- | --- | --- |
| 濡れたまま戻す | カビ・においの原因に | 完全に乾かす。急ぐ日は掃除機がけだけにする |
| 硬いブラシで強くこする | 網の目が伸びて集塵力が落ちる | 柔らかいブラシでなでる |
| お湯で洗う | 樹脂の変形 | 水かぬるま湯まで |
| 向きを間違えて戻す | パネルが閉まらない・外れやすい | 外す前にスマホで1枚撮っておく |
| ついでに奥のフィンを掃除 | フィン曲がり・故障 | 奥は触らない。気になるなら[プロのクリーニング](/articles/cleaning-spray-risk/)へ |

## 頻度の目安

| 環境 | 目安 |
| --- | --- |
| 夏・冬の使用期（基本） | 2週間に1回 |
| ペットがいる・キッチンが近い | 1週間に1回 |
| 交通量の多い道路沿い | 1〜2週間に1回 |
| ほぼ使わない季節 | 使い始めの前に1回 |

毎回水洗いする必要はありません。「こまめな掃除機がけ＋月1回の水洗い」くらいの組み合わせが続けやすいです。シーズン初めの試運転日（冷房なら梅雨入り前）に1回掃除しておくと、真夏の不調をかなり防げます。

## お掃除機能付きエアコンの場合

「フィルター自動お掃除」付きでも、手入れが不要になるわけではありません。

- 自動掃除で集めたホコリが溜まる**ダストボックスの清掃**は手作業です（頻度は機種により異なる。取扱説明書を確認）
- 油分や細かい汚れは自動掃除では取れないため、定期的なフィルターの水洗いは依然有効です
- 内部の構造が複雑なぶん、内部洗浄のセルフ作業は通常機よりさらに危険です

## 掃除しても改善しない時

フィルターをきれいにしても風が弱い・冷えない場合は、フィルター以外の原因(室外機まわり、冷媒、内部の汚れ)が考えられます。[冷えない時の確認手順](/articles/not-cooling/)で切り分けを進めてください。掃除してもにおいが残る場合は、内部のカビが進んでいる可能性があり、[においの原因と対処](/articles/smell-odor/)が参考になります。
