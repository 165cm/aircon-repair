エアコンの購入で「工事費込み」と書かれていても、現地の状況によって追加費用が発生することがあります。事前に確認しておくことで、見積もりと実際の請求額の差を防ぎやすくなります。

## 標準工事の範囲（目安）

標準工事は条件が揃った場合の基本工事です。販売店や工事業者によって内容が異なるため、必ず事前確認が必要です。

| 項目 | 標準工事の目安 |
| --- | --- |
| 配管カバー | 含まれない場合が多い |
| 配管延長 | 2〜3m以内が基本（延長で追加） |
| 既設機の取り外し・処分 | 別料金が多い |
| 専用コンセント増設 | 別途電気工事費が必要 |
| 室外機の特殊設置 | 屋根置き・壁面置きは追加 |

## 追加工事費が発生しやすいケース

**配管の延長が必要な場合**

室内機と室外機の設置場所が離れている時は、配管を延長します。1mあたり数千円の追加が一般的です。

**専用回路・コンセントがない場合**

エアコンは専用コンセントが必要です。既存のコンセントが共用タイプだったり、200V機種なのに100Vしかない場合は電気工事が必要で、1〜3万円程度の追加費用がかかることがあります。

**室外機の特殊設置**

通常の地置きではなく、屋根置きや壁面設置、マンションのベランダに架台が必要な場合は別途料金が発生します。

**既設エアコンの取り外しと処分**

古いエアコンがある場合は取り外し工事費（5,000〜15,000円程度）と、リサイクル料金（別途）が必要です。

## 工事前に確認しておくべきこと

- [ ] 配管穴がすでに開いているか
- [ ] 専用コンセントの有無と電圧（100V or 200V）
- [ ] 室外機の置き場所と地面・ベランダの状態
- [ ] 配管の長さの目安
- [ ] 既設機の取り外し・処分の有無と費用
- [ ] マンションの場合、管理規約での工事制限の有無

## 畳数別の本体+工事費の目安

| 畳数 | 本体+標準工事の目安 | 注意点 |
| --- | --- | --- |
| 6畳 | 7〜12万円台 | 単身・個室向け |
| 8〜10畳 | 9〜16万円台 | リビング・夫婦寝室向け |
| 14畳以上 | 15〜30万円台以上 | 200V機種が多い。電気工事費に注意 |

※価格は工事費込みの目安です。実際の費用は現地調査で確認してください。

## 複数社で見積もりを取ることが安心

購入店の工事費が必ずしも一番安いとは限りません。量販店・工事専門業者・購入店付きの業者など、条件が同じ前提で複数社を比較すると、数万円の差が出ることがあります。

「工事費込み」の表示でも、現地で追加費用が発生するケースは多いため、事前に追加費用の条件を文書で確認しておくことが大切です。
