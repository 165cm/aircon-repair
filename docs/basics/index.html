1時間目: 基礎

エアコンの基礎知識

空気を冷やす仕組みを、冷媒は「熱を運ぶガス」、ドレンホースは「水を外へ流す管」のように、身近な言葉へ置き換えて理解します。

高校生でも分かる用語

専門用語ミニ解説

難しい言葉は、まず生活の言葉に置き換えてから読み進めます。

冷媒

熱を運ぶためのガス

エアコンの中を回って、部屋の熱を外へ運びます。漏れや補充は資格・専用工具が必要な領域です。

熱交換器

空気の熱を受け渡しする金属部品

室内機の奥にある薄い金属のフィンです。曲がりやすく、内部洗浄は業者向けです。

ドレンホース

冷房で出た水を外へ流すホース

冷房中の結露水を外へ逃がします。先端の詰まり確認はできますが、高所や室内機の分解は避けます。

室外機

外で熱を逃がす箱

冷房時は部屋から集めた熱を外へ捨てます。周囲をふさぐと冷えにくくなります。

基板

エアコンを動かす電子部品の板

電源やセンサーを制御します。焦げ臭い、動作が不安定などの症状は自分で触らず相談します。

200V

大きめのエアコンで使うことがある強い電源

14畳以上などで出てきます。コンセント形状や専用回路の判断は販売店・電気工事士へ確認します。

専用回路

エアコンだけが使う電気の通り道

他の家電と同じ回路だとブレーカーが落ちやすい場合があります。増設や変更は電気工事です。

標準工事

販売店が決めた基本の取り付け工事

配管の長さ、室外機の置き方、穴あけ、古い機種の処分などで追加費用が出ることがあります。

危険サインあり

エアコン修理を呼ぶ目安と依頼前メモ

修理業者やメーカーへ相談するべき危険サイン、依頼前にメモしておく情報、繁忙期の動き方をまとめます。

basics 初心者向け 修理危険サイン

低リスク

高校生レベルで分かるエアコンの仕組み

エアコンが部屋を冷やす仕組みを、熱、冷媒、室内機、室外機の役割に分けてやさしく説明します。

basics 初心者向け 仕組み冷えない

注意

エアコンが冷えない時の原因と安全チェック

冷房が効かない時に、初心者が安全に確認できるフィルター、室外機、設定、熱中症リスクの見方を整理します。

symptom 初心者向け 冷えない暑い室外機

低リスク

エアコンのリモコンが効かない時の切り分け

電池交換、赤外線確認、本体応急運転など、リモコン不調を安全に切り分ける手順を解説します。

symptom 初心者向け リモコン電源

危険サインあり

エアコンの異音で止めるべき音・様子を見る音

symptom 初心者向け 異音室外機

注意

エアコンから水漏れする時の応急確認

symptom 初心者向け 水漏れ排水
