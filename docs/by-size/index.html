サイズアップ

能力不足は「故障ではない冷えない」原因

部屋が広い、日当たりが強い、LDK続き、最上階、古い木造では、表示畳数どおりでも冷えにくいことがあります。

工事費

本体価格だけで判断しない

標準工事、配管延長、化粧カバー、室外機特殊設置、電源変更は追加費用になりやすい項目です。

高単価CV

修理見積もりと同時に比較

10年以上使用、複数症状、修理費が新品の半額前後なら、修理相談と本体候補の比較を並行します。

購入前は「標準工事込み」の範囲、既存配管を使うか、配管穴、室外機置き場、コンセント形状、100V/200Vを確認してください。電源変更や専用回路の工事は資格者・販売店へ相談します。
