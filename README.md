# エアコン修理高等学校

夏のエアコン不調に向けた、初心者向けの安全確認・商品紹介・求人導線つきAstro静的サイトです。

## セットアップ

```bash
npm install
npm run dev
npm run build
```

公開前に `src/data/affiliate.ts` のAmazonアソシエイトID、業者紹介URL、求人ASP URLを実際の値に差し替えてください。

## 方針

- 自力でできる範囲はフィルター、外装、室外機まわり、ドレンホース先端の確認まで。
- 内部洗浄、電気配線、冷媒、分解修理、200Vまわりは専門業者・資格者へ誘導。
- 全ページに広告・Amazonアソシエイト表記を表示。
- Amazonリンクは共通コンポーネントで生成し、クリック計測用の `dataLayer` イベントを送信。
- 畳数別記事と商品個別ページで、修理費が高い時の買い替え比較導線を用意。
