# エアコン保健室

![Tier](https://img.shields.io/badge/Tier-T0-lightgrey) ![Category](https://img.shields.io/badge/Category-work-blue)

症状から次の一手を選ぶエアコントラブル対処ガイド

公開URL: https://165cm.github.io/aircon-repair/

## これは何

エアコンの不調に困った人が、危険な作業に踏み込まず、症状ごとに次の行動を選べるようにする情報サイトです。

## こんな時に

- 冷えない、水漏れ、異音、リモコン不調など、エアコンの調子が悪い
- 自分で確認できる範囲と、業者に頼むべき範囲を知りたい
- 修理費が高い時や10年以上使っている時に、買い替えを検討したい
- 安全な補助用品（温湿度計・掃除用品・ドレン対策）を探したい

## 使い方

初めて読む場合は「基礎知識」から順番に読むと全体像をつかみやすくなります。

- [基礎知識](https://165cm.github.io/aircon-repair/basics/): 10〜15分でエアコンの仕組みと安全確認の範囲を学ぶ。
- [症状診断](https://165cm.github.io/aircon-repair/diagnosis/): 今起きている症状から次の行動を選ぶ。
- [畳数で選ぶ](https://165cm.github.io/aircon-repair/by-size/): 修理か買い替えか迷う時に部屋の広さから確認する。
- [商品比較](https://165cm.github.io/aircon-repair/products/): 安全な補助用品や買い替え候補を見る。

## 安全方針

このサイトでは、読者が自分で確認してよい範囲を限定しています。

- **自分で確認してよい範囲**: フィルター、外装、室外機まわり、ドレンホース先端
- **専門家へ相談する範囲**: 内部洗浄、電気配線、冷媒、分解修理、200Vまわり
- **使用を止めて相談するサイン**: 焦げ臭い、強い異音、水漏れが広がる、ブレーカーが落ちる、室外機が異常に熱い
